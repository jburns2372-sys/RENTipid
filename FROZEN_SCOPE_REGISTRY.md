# Frozen Scope Registry

1. **Security Foundation**: JWT, correlation ID, API event ingestion.
2. **Policy Foundation**: DB Schema, Prisma Client, Typescript interfaces, vocabulary validation.
3. **Azure Listing Lifecycle**: Listing workflow, approvals, drafts, reviews.
4. **Provider Listing Enforcement**: Active evaluation engine, enforcement case creation, auto-block for PROHIBITED, CRITICAL security event escalation.
5. **Public Module**: Client-side catalog search.
6. **Admin Compliance & Appeals**: Case resolution and RBAC validation.
