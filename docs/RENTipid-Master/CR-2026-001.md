# CR-2026-001 — Identity/Auth fail-closed hardening

Status: IN IMPLEMENTATION

Frozen baseline protected: historical authentication instrumentation, SOC proxy boundary and Address release `6f55296cdf1ff2bda3c550448fc307f264f1f397`

## Reopen reason

The one-time reconciliation confirmed two known-secret fallbacks, account enumeration through credential error text, and optimistic dashboard routing that did not reject suspended, blacklisted, malformed-status or pending privileged tokens.

## Change scope

- Remove `NEXTAUTH_SECRET` fallback from NextAuth and Proxy.
- Fail closed with 503 before token processing when Proxy secret configuration is absent.
- Centralize account-state decisions.
- Allow Pending non-privileged users only on onboarding/profile/KYC/privacy surfaces.
- Deny Pending privileged, Suspended, Blacklisted and unknown status values.
- Keep proxy checks optimistic; authoritative server/API authorization remains required.
- Return generic credential errors to prevent account enumeration.
