## Known route gaps

- No password recovery/reset routes.
- No renter-provider messaging routes.
- No notification inbox routes.
- No dedicated review submission route was found.
- Support and feedback pages are shells without accepted submission mutations.
- Several server-side capabilities use Server Actions rather than route handlers; those are governed in the feature and API registers by their owning module.
