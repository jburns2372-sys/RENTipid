## 3. Controlling Architecture Mandate

The Project Owner has explicitly reaffirmed the non-negotiable architectural principles for GLOBAL-MKT:

1. **ONE GLOBAL MARKETPLACE PLATFORM:**
   - NOT 46 standalone applications.
   - NOT country-specific marketplace forks.
   - NOT duplicated booking engines by country.
   - NOT duplicated payment engines by country.
   - NOT duplicated listing engines by country.

2. **Core Composition:**
   ```
   GLOBAL CORE
     + JURISDICTION PROFILE
     + CAPABILITY REGISTRY
     + POLICY ENGINE
     + PROVIDER ADAPTERS
   ```

3. **Authoritative Country Inventory:**
   - Derive strictly from the existing 46-country catalog in GLCC.
   - No secondary duplicated country registry.

4. **Zero Initial Commercial Active Jurisdictions:**
   - Full commercial activation count remains `0` until complete end-to-end multi-capability lifecycle acceptance is achieved under the Universal Promotion Standard.
   - Philippines, China, and Thailand remain non-active commercially at GM-0 / GM-1 baseline.
